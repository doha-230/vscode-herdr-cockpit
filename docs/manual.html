화면 구성

Local

현재 VS Code 확장이 실행되는 컴퓨터의 Herdr 공간과 에이전트입니다. Windows에서는 Herdr named pipe, Linux에서는 Unix 소켓으로 연결합니다.

SSH 호스트

등록한 Linux/macOS 호스트별 공간을 같은 사이드바에 묶어 표시합니다. 원격 에이전트의 상태와 Needs you 알림도 합산됩니다.

설치와 준비

  1. VSIX 설치
    VS Code에서 Extensions: Install from VSIX…를 실행하고 위의 v0.3.0 파일을 선택합니다. 터미널에서는 code --install-extension herdr-cockpit-0.3.0.vsix를 사용할 수 있습니다.
  2. 로컬 Herdr 준비
    로컬 Herdr 서버를 실행합니다. 설치되어 있다면 사이드바의 Start Herdr로 시작할 수도 있습니다.
  3. VM 준비
    Linux VM에 OpenSSH 서버와 Herdr를 설치하고 Herdr 서버를 실행합니다. Windows에서 VM의 SSH 주소와 포트에 접속할 수 있어야 합니다.
  4. 로컬 VS Code 창 사용
    Windows 데스크톱과 VM을 동시에 보려면 Windows의 로컬 VS Code 창에서 확장을 실행합니다. Remote-SSH 창에서 실행하면 그 원격 서버가 Local로 취급됩니다.

Windows → Linux VM: SSH 키 연결

Windows의 %USERPROFILE%\.ssh\config에 호스트 별칭을 등록합니다. IP, 계정, 키 파일 경로를 실제 VM 값으로 바꾸세요. 포트가 22가 아니면 Port도 지정합니다.

Host vm-linux
    HostName 192.168.56.10
    User ubuntu
    Port 22
    IdentityFile ~/.ssh/id_ed25519
    IdentitiesOnly yes

PowerShell에서 아래 명령으로 인증과 Herdr 실행을 확인합니다. vm-linux는 위에서 정한 별칭입니다.

ssh -o BatchMode=yes vm-linux "herdr status server --json"

암호로 보호한 키는 미리 Windows ssh-agent에 등록하세요. 확장은 BatchMode=yes를 사용하므로 연결 도중 암호나 키 암호를 입력받지 않습니다. Herdr가 VM의 일반 PATH에 없으면 아래 설정의 binaryPath를 지정합니다.

호스트 추가: 명령 팔레트에서 Herdr Cockpit: Add SSH Host…를 실행해 vm-linux를 입력하거나 사이드바 아래의 Add SSH host…를 누릅니다. 확장은 같은 SSH 설정의 키, 포트, 점프 호스트를 사용합니다.

표시 이름이나 원격 Herdr 경로를 바꾸려면 VS Code 사용자 설정에 다음을 추가합니다.

"herdr.remoteHosts": [
  {
    "host": "vm-linux",
    "label": "개발 VM",
    "binaryPath": "/home/ubuntu/.local/bin/herdr"
  }
]

원격 소켓을 자동으로 찾지 못할 때만 "socketPath": "/home/ubuntu/.config/herdr/herdr.sock"처럼 절대 Unix 소켓 경로를 추가합니다. 실제 경로는 VM에서 herdr status server --json으로 확인하세요.

사이드바에서 작업하기

공간과 터미널

원격 공간을 선택하면 Herdr에서 그 공간에 포커스를 맞추고 해당 pane을 SSH 터미널 탭으로 엽니다. 에이전트와 셸은 VM에서 계속 실행됩니다.

생성·관리

원격 공간 또는 탭을 만들고, 에이전트를 시작하며, 이름을 변경하거나 닫을 수 있습니다. 호스트의 × 버튼은 목록에서 호스트만 제거합니다.

폴더 열기

Open folder는 VS Code Remote-SSH 확장으로 해당 VM 폴더를 별도 창에 엽니다. 원격 파일 탐색기, Git, diff는 그 창에서 사용합니다.

호스트별 정보

통합 사이드바는 원격 상태와 Needs you를 표시합니다. 원격 사용량 및 Git 정보는 해당 Remote-SSH 창에서 확인합니다.

트리 접기·펼치기 기억

공간 카드, 셸 그룹, 에이전트 상세 정보, Usage 영역의 펼침 상태를 작업 공간별로 저장합니다. 같은 작업 공간을 다시 열면 복원되며, 로컬과 각 SSH 호스트의 상태는 서로 구분됩니다.

다른 VS Code 작업 공간은 각자의 펼침 상태를 가집니다.

문제 해결

SSH 호스트가 연결되지 않음

PowerShell에서 ssh -o BatchMode=yes vm-linux "herdr status server --json"을 실행하세요. 인증 실패면 SSH 키·ssh-agent·VM 주소·포트를 확인합니다. Herdr 명령을 찾지 못하면 binaryPath를 설정합니다.

VM 접속은 되는데 Herdr가 보이지 않음

VM에서 Herdr 서버 실행 상태와 소켓 경로를 확인합니다. 확장은 Herdr가 보고한 절대 Unix 소켓 경로로 터널을 엽니다. VM의 SSH 서버가 포워딩을 허용해야 합니다.

Windows 로컬 Herdr에 연결되지 않음

herdr.binaryPath가 실제 herdr.exe 파일을 가리키는지 확인하세요. herdr.socketPath에는 named pipe 접두사가 아닌 Herdr의 논리적 소켓 경로를 입력합니다.

원격 폴더의 Git과 diff가 통합 사이드바에 없음

원격 공간의 Open folder를 눌러 Remote-SSH 창을 여세요. 원격 파일 작업은 그 창에서 제공됩니다.
